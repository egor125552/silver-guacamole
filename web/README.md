# Stealth Action Web

Полный браузерный порт C++-прототипа. C++ остаётся архивным экспериментом; дальнейшие механики можно развивать здесь без компиляции.

Игра построена из маленьких ES-модулей-плагинов. Единственный список активных механик находится в `js/plugins/registry.js`. Отключение строки плагина убирает соответствующую механику без переписывания ядра.

Оригинальные звуки берутся из корневой папки `sounds` без перекодирования. Синтезированные сигналы создаются Web Audio API с параметрами из C++-версии.

Пространственный звук собран отдельным `spatial-router` плагином. Передняя полусфера преимущественно использует точное stereo-позиционирование; между 55 и 120 градусами сигнал плавно переходит в HRTF; задняя полусфера работает преимущественно через HRTF и получает мягкую спектральную подсказку для различения переда и зада.

После пространственного этапа абсолютно все звуки попадают в один общий `environmentInput`. Из него единообразно формируются dry и convolution-reverb ветки, поэтому оружие, шаги, сонар, NPC, относительные сигналы и ambience больше не используют разные схемы реверберации. Переключение generic/cave сделано плавным кроссфейдом между двумя convolution-профилями.
